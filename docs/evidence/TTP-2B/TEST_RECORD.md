## Browser evidence

The Playwright browser suite retained one full-page screenshot for every accepted route and each viewport width: `screenshots/1440/`, `screenshots/1024/`, `screenshots/768/`, and `screenshots/375/`. It checked visible page rendering, browser console and page errors, failed requests and error responses, horizontal overflow, accessible names for controls/links/images, keyboard focus, mobile navigation, the first-time wizard preview, and back-office review tabs. The first API inventory attempt exposed an over-specific expected-error regular expression; it was corrected and the final loopback and origin-override tests passed.

The four matched visual-reference screenshots are under `visual-regression/`. Pixel differences were 0.3952%–0.7425%, below the recorded 1% allowance for Firefox 159 versus the older accepted Firefox rasterization. Each comparison also confirmed a visible primary heading. Initial direct Firefox CLI capture and strict zero-difference attempts are preserved in [visual-baseline-cli-attempt.log](visual-baseline-cli-attempt.log) and [visual-baseline-zero-diff-attempt.log](visual-baseline-zero-diff-attempt.log); the CLI capture raced the heading paint, and exact pixel equality was not appropriate across Firefox builds. The final repeatable Playwright capture waits for network idle and fonts.
